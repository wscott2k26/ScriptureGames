# Scripture Games Support

Need help with Scripture Games or want to report a beta issue?

**Email:** [loftlatte25@gmail.com](mailto:loftlatte25@gmail.com)

Please include:

- Your iPhone model and iOS version
- The Scripture Games version/build number
- What screen you were using
- The steps that caused the problem
- A screenshot, when possible

Do not include passwords, payment information, medical details, or other sensitive information.

## Common beta fixes

1. Force-close Scripture Games and reopen it.
2. Confirm the latest TestFlight build is installed.
3. Restart the iPhone if the issue continues.
4. For a clean beta reset, use **Journey → player menu → Erase All App Data**. This removes local Scripture Games progress from the device.
